# Macropad
My personal macropad for digital art, gaming and more,featuring a rotary encoder and OLED display.

## Features
- **3x3 Mechanical Key Grid**: Fully programmable.
- **Rotary Encoder**: Smooth scrolling or volume control.
- **128x32 OLED**: Real-time feedback and mode indication.
- **CircuitPython Powered**: Easy to drag-and-drop code changes.

## Folder Structure
- `/CAD`: 3D printable files for the top and bottom case.
- `/Firmware`: `code.py` and asset files.
- `/PCB`: Schematic and layout files.

## Build Requirements
- 9x Mechanical Switches
- 1x EC11 Rotary Encoder
- 1x SSD1306 OLED Display (I2C)
- 1x Microcontroller (RP2040 recommended)
